# Breaking Template Protection

This FG 2024 paper studies learned reconstruction from protected facial templates, including BioHashing, MLP-Hashing, and homomorphic encryption. Its stated threat model is full disclosure/high knowledge. That is useful as a vulnerability baseline but does not establish leakage with unknown keys.

No official code source was verified in this audit. Reproduction therefore remains **NOT REPRODUCIBLE YET** until an authors' implementation or exact independently sufficient protocol is confirmed.
