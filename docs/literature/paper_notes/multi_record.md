# Multiple-record work

The cited work is Cai Li and Jiankun Hu, "Attacks via Record Multiplicity on Cancelable Biometrics Templates," *Concurrency and Computation: Practice and Experience* 26(8), 1593-1605 (2014), DOI `10.1002/cpe.3042`. Publisher abstract and metadata checked 18 September 2026: four cancelable fingerprint schemes, multiple templates and corresponding transformation parameters. This is cryptanalysis, not learned unknown-key identity extraction. The previously recorded DOI was unrelated and has been corrected.

The later maximal-leakage paper measures linkability across multiple protected templates. It should inform evaluation language, but measurement of linkability is different from recovering an ArcFace-aligned embedding from a set. The claimed public source code and exact commit remain unverified.
