# Sani survey

Abdullahi et al., *Information Fusion* 103 (2024), 102144, DOI `10.1016/j.inffus.2023.102144`, categorizes attacks by system vulnerability point and prerequisite attacker knowledge. It distinguishes attacks with templates, key parameters/secret keys, similarity scores, and decision-function knowledge. This supports explicitly separating K0 (algorithm-family-known, keys unknown) and K1 (parameters-known, keys unknown) rather than describing an attacker loosely as low knowledge.
